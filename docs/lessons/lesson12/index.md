# lesson12: 認知心理学 — UXデザインに活きる心理法則

## このレッスンで学ぶこと

- 認知心理学とUXデザインの関係を理解する
- ユーザーの期待と慣れに関する法則（ヤコブの法則・自動認知処理）を知る
- 認知の負担に関する法則（ヒックの法則・認知負荷・ドハティのしきい値）を知る
- 見た目と知覚に関する法則（美的ユーザビリティ・シグニファイア・ゲシュタルトの原則）を知る

## 認知心理学とは

認知心理学とは、人間の**知覚・記憶・思考といった情報処理の仕組み**を研究する学問です。

UXデザインの現場では、認知心理学の研究から導かれた法則がデザイン原則として広く使われています（書籍『UXデザインの法則』などで体系化されています）。

このレッスンでは代表的な法則を「期待と慣れ」「認知の負担」「見た目と知覚」の3グループに分け、「法則の内容」と「UXデザインでの活かし方」のセットで整理します。

## ユーザーの期待と慣れに関する法則

### ヤコブの法則

ユーザーは他のサイトやアプリで積み重ねた経験をもとに、「このサイトも同じように動くはず」と期待する、という法則です。ユーザビリティ研究で知られるヤコブ・ニールセンが提唱しました。

**UXデザインでの活かし方**

- ナビゲーションやアイコンは、世の中の一般的な慣習（ユーザーのメンタルモデル）に合わせる
- 独自性の高いUIは新鮮に見えても、ユーザーに学習の負担を強いる

### 自動認知処理

人の認知処理には、意識的で努力を要する処理と、無意識的で速い**自動的な処理**の2種類があります。使い慣れた操作は自動認知処理で実行されるため、ユーザーは画面の文章を熟読せず、いつもの場所をいつもの手順で操作します。

**UXデザインでの活かし方**

- ユーザーが「読まずに操作する」前提でレイアウトを設計する
- 削除などの重要な確認では、色やレイアウトを変えて自動的な操作の流れを意図的に中断させる

## 認知の負担に関する法則

### ヒックの法則

選択肢の数が多いほど、意思決定にかかる時間が長くなる、という法則です。

**UXデザインでの活かし方**

- 選択肢を絞り込む、またはカテゴリ分けして段階的に提示する
- 迷わせたくない場面では、おすすめやデフォルトの選択肢を用意する

### 認知負荷

認知負荷とは、課題をこなすために必要な頭の働きの総量です。大きく2つに分けられます。

| 種類 | 内容 | 例 |
|------|------|-----|
| 内在的認知負荷 | 課題そのものの難しさによる負荷 | 保険プランの比較検討そのものの複雑さ |
| 外在的認知負荷 | 情報の提示のされ方など、課題の本質と無関係な要因による負荷 | 読みにくいレイアウト、わかりにくい専門用語 |

**UXデザインでの活かし方**

- デザインで減らせるのは主に**外在的認知負荷**。情報の整理・平易な言葉・入力補助で取り除く
- 内在的認知負荷は、分割して少しずつ提示することで負担を分散できる

### ドハティのしきい値

システムの応答が**0.4秒（400ミリ秒）以内**であれば、人は集中を保ったまま快適に作業を続けられる、という法則です。

**UXデザインでの活かし方**

- 応答速度そのものを改善することが第一
- すぐに結果を返せない処理では、プログレスバーやスケルトン画面で「進んでいる」と感じさせ、体感の待ち時間を短くする

## 見た目と知覚に関する法則

### 美的ユーザビリティ

見た目が美しいデザインは、実際よりも**使いやすいと知覚される**、という効果です。

**UXデザインでの活かし方**

- 見た目の品質は第一印象と満足度に直結するため、軽視しない
- 一方で、見た目の良さがユーザビリティ上の問題を覆い隠すことがある。ユーザーテスト（[lesson28](/lessons/lesson28/)）では発言だけでなく行動を観察する

### シグニファイア

シグニファイアとは、**どこを操作でき、どう操作すればよいかをユーザーに伝える手がかり**のことです。認知科学者のドナルド・ノーマンが提唱しました。

| 用語 | 意味 |
|------|------|
| アフォーダンス | 環境やモノがもつ「行為の可能性」そのもの（押せる・つかめるなど） |
| シグニファイア | その可能性をユーザーに知らせる手がかり（ボタンの影、リンクの下線など） |

**UXデザインでの活かし方**

- 押せるものは押せるように見せる。クリックできる要素とできない要素を見た目で区別する
- 装飾を削ぎ落としたデザインでは操作の手がかりが失われやすいため、意識的に補う

### ゲシュタルトの原則

人は個々の要素をバラバラにではなく、**まとまり（ゲシュタルト）として知覚する**、という知覚心理学の原則群です。

| 原則 | 内容 | UXデザインでの活かし方 |
|------|------|------------------------|
| 近接 | 近くにあるもの同士は仲間に見える | 関連する項目を近づけ、余白でグループを区切る |
| 類同 | 色や形が似たもの同士は仲間に見える | 同じ役割のボタンやリンクは同じ見た目に統一する |
| 連続 | 並んだものはひとつながりの流れとして見える | 整列によって視線の流れをつくる |
| 閉合 | 一部が欠けた図形も、閉じた形として補って知覚される | 画面端で見切れたカードで「横に続きがある」と伝える |

## キーワード

| 用語 | 説明 |
|------|------|
| ヤコブの法則 | ユーザーは他のサイトでの経験をもとに、同じ動きを期待する |
| ヒックの法則 | 選択肢が多いほど意思決定に時間がかかる |
| 認知負荷 | 課題に必要な頭の働きの総量。内在的・外在的に分けられる |
| 美的ユーザビリティ | 美しいデザインは実際より使いやすいと知覚される効果 |
| 自動認知処理 | 慣れた操作が無意識的・自動的に処理されること |
| ドハティのしきい値 | 応答が0.4秒以内なら快適に作業を続けられるという基準 |
| シグニファイア | 操作の方法を伝える手がかり。アフォーダンスを知らせるサイン |
| アフォーダンス | 環境やモノがもつ行為の可能性そのもの |
| ゲシュタルトの原則 | 要素をまとまりとして知覚する原則群（近接・類同・連続・閉合など） |

## 試験のポイント

- 法則名と内容の対応が問われやすい。「ヤコブ＝他サイトでの経験」「ヒック＝選択肢の数と時間」「ドハティ＝**0.4秒**」を確実に結びつける
- 認知負荷の**内在的**（課題そのもの）と**外在的**（提示のされ方）の区別を覚える
- **シグニファイアとアフォーダンスの違い**は頻出。可能性そのものがアフォーダンス、それを伝える手がかりがシグニファイア
- ゲシュタルトの原則は、近接・類同・連続・閉合の各原則名と具体例を対応づけられるようにする
- 美的ユーザビリティは「美しいと**使いやすく感じられる**」という知覚の効果であり、実際に使いやすくなるわけではない点に注意
