# lesson35: 体験品質ディレクション力・高速改善力 — AIのアウトプットを方向づける

## このレッスンで学ぶこと

- 体験の品質基準の作り方と、品質最終責任者の役割を説明できる
- 高速改善力のサイクルを説明できる
- Human in the LoopとExpert in the Loopの違いを説明できる

## 体験の品質基準

AIを使えば画面案・文章案・プロトタイプ・コンテンツ・対話設計などを短時間で大量に作れますが、大量に作れることとよい体験であることは別問題です。そこで必要になるのが**体験の品質基準**です。

品質基準は、次の型で表現できます。

> `○○な状況で、△△ができずにいる人を、□□に導けていること`

この型は、次の3つを明確にします。

1. どのような状況に置かれたユーザーを対象にするのか
2. そのユーザーは何ができずに困っているのか
3. そのユーザーをどのような状態へ導くのか

たとえば、「忙しくて献立を考える余裕がない人を、無理なく栄養バランスのよい食事を準備できる状態に導けていること」のように表現します。

品質基準がないと評価が曖昧になり、声の大きい人の意見が通る、見た目の好みで判断される、AIが出したものをそのまま採用してしまう、といった問題が起こります。

**体験品質ディレクション力**とは、AIや開発者が作ったアウトプットを見て、定義した品質基準に合っているかを評価し、必要に応じて修正方針を言語化する力です。この力の土台には、[lesson32](/lessons/lesson32/)のユーザー視点での体験理解力と、[lesson34](/lessons/lesson34/)の体験構造化力が必要になります。

## 品質最終責任者の役割

品質基準の定義から実際のアウトプット評価までを、合議体ではなく特定の「**品質最終責任者**」が担う形が理想的とされます。体験の品質には「深い理解」に基づく「体験価値への強いこだわり」が関わるため、最終的にどのような体験を提供し何を優先するかは、合議だけでは決めにくいためです。

品質最終責任者の役割には、品質基準の定義と運用、AIや開発者のアウトプットの評価、ユーザー状況とのズレの検知、修正方針の言語化などが含まれます。プロダクトオーナーやUX責任者がこの役割を担うことが考えられます。

## 高速改善力

AI時代にはアイデアやアウトプットを作るスピードが上がり、これまで数日かかっていた案出しや文章作成が数分から数時間でできることもあります。速く作れるようになるからこそ、速く改善する力が重要になります。最初のアウトプットは仮説にすぎず、実際のユーザーや専門家にぶつけて反応を見ながら改善していく必要があるためです。

**高速改善力**とは、次のサイクルを回す力です。

```mermaid
graph LR
    A[仮説を立てる] --> B[すばやく\n作る]
    B --> C[試して\nもらう]
    C --> D[フィードバック\nを得る]
    D --> E[問題点を\n構造化する]
    E --> F[修正方針を\n立てる]
    F --> A
```

## Human in the LoopとExpert in the Loop

AIの活用でよく使われる考え方に**Human in the Loop**があります。AIの判断や出力のプロセスに人間が関与し、確認・修正・判断に加わることで品質や安全性を高める考え方です。AIが生成した文章を人間が確認してから公開する、といった形で、AIの誤りを防ぐうえで重要です。

さらに踏み込んだ考え方が**Expert in the Loop**です。AIの意思決定・出力プロセスの途中に、その分野の専門家が関与する設計思想です。Human in the Loopが「人間が関与する」ことを重視するのに対し、Expert in the Loopは「その領域の専門家が関与する」ことがポイントです。医療AIなら医師、法律AIなら弁護士、営業支援AIなら優秀な営業マネージャーが関与することで、単なる表面的な修正ではなく、その領域の成功要件やノックアウト要件を精緻に把握できます。

Expert in the Loopでは、専門家のフィードバックをどう深掘り・構造化できるかが鍵になります。AIが出した助言に専門家が違和感を示したとき、単に言い回しを直すのではなく、「なぜその表現がよくないのか」「どのような目的なら別の表現を選ぶのか」を深掘りすることで、AIが守るべき品質基準や避けるべきノックアウト要件が見えてきます。

| 考え方 | 関与する人 | ねらい |
|------|-----------|------|
| Human in the Loop | 人間一般 | AIの誤りを防ぎ、品質・安全性を高める |
| Expert in the Loop | その領域の専門家 | 領域固有の成功要件・ノックアウト要件を精緻に把握する |

## キーワード

| 用語 | 説明 |
|------|------|
| 体験の品質基準 | 「`○○な状況で、△△ができずにいる人を、□□に導けていること`」の型で表す体験の要件 |
| 品質最終責任者 | 品質基準の定義から評価までを担う役割。プロダクトオーナーやUX責任者が担うことが多い |
| 高速改善力 | 仮説を立て、作り、試し、フィードバックを得て改善するサイクルを速く回す力 |
| Human in the Loop | AIの判断・出力プロセスに人間が関与する考え方 |
| Expert in the Loop | AIの判断・出力プロセスにその領域の専門家が関与する設計思想 |

## 試験のポイント

- 品質基準の型「`○○な状況で、△△ができずにいる人を、□□に導けていること`」の3要素を押さえる
- 品質基準の合議判断ではなく、品質最終責任者が担う形が理想とされる理由を理解する
- Human in the Loop（人間の関与）とExpert in the Loop（専門家の関与）の違いを区別する
