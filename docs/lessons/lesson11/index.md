# lesson11: 行動経済学 — 人は合理的に行動しない

## このレッスンで学ぶこと

- 行動経済学の基本的な考え方（人の合理性には限界がある）を理解する
- 代表的な認知バイアスと、UXデザインへの影響を知る
- プロスペクト理論のポイント（参照点・損失回避）を説明できる
- ナッジとEASTフレームワーク、活用時の注意点を理解する

## 行動経済学とは

行動経済学とは、**実際の人間がどのように意思決定しているか**を研究する学問です。

伝統的な経済学は「人は合理的に行動するはず」という前提（規範的アプローチ）に立ちます。これに対して行動経済学は「人は実際にはどう行動しているか」（記述的アプローチ）に注目します。

### 合理性の限界

行動経済学の出発点は、**人の合理性には限界がある**という事実です。

- 人の時間・情報・能力には限界がある（**限定合理性**）
- そのため人は思考のショートカット（**ヒューリスティック**）に頼って判断する
- ヒューリスティックは、判断の系統的な偏り（**認知バイアス**）を生む

```mermaid
graph LR
    A[限定合理性\n合理性には限界がある] --> B[ヒューリスティック\n思考のショートカット]
    B --> C[認知バイアス\n判断の系統的な偏り]
    C --> D[ナッジ\nバイアスを踏まえた\n選択環境の設計]
```

::: info UXデザインとの関係
ユーザーの行動は、機能の良し悪しだけでなく**環境や情報の提示のされ方**に大きく影響されます。同じ選択肢でも、見せ方や並べ方を変えるだけで選ばれ方が変わります。この性質を理解することが、ユーザーの意思決定に寄り添ったUXデザインの前提になります。
:::

## 代表的な認知バイアス

認知バイアスとは、判断や意思決定に生じる系統的な偏りのことです。UXデザインと関わりの深いものを整理します。

| バイアス | 内容 | UXデザインでの例 |
|----------|------|------------------|
| アンカリング効果 | 最初に提示された情報（アンカー）が基準になり、その後の判断が引きずられる | 定価を併記して割引価格を示すと安く感じられる |
| 損失回避 | 同じ大きさでも、利得より損失のほうを強く感じる | 「期限を過ぎるとポイントが失効します」という通知のほうが行動を促す |
| 現状維持バイアス | 変化を避けて現状を保とうとする | 初期設定（デフォルト）がそのまま使われ続けやすい |
| 社会的証明 | 多くの人がしている行動を正しいと感じて従う | レビュー件数や「人気No.1」の表示が選択を後押しする |
| フレーミング効果 | 同じ内容でも、表現の枠組みによって判断が変わる | 「成功率90%」と「失敗率10%」では受け取られ方が異なる |

## プロスペクト理論

プロスペクト理論は、カーネマンとトベルスキーが提唱した、不確実な状況での意思決定を説明する理論です。人が価値をどう感じるかについて、3つの特徴を示しています。

- **参照点依存性**: 価値は絶対的な量ではなく、参照点（基準となる点）からの変化として評価される
- **損失回避性**: 損失は、同じ大きさの利得よりも強く評価される
- **感応度逓減性**: 利得も損失も、変化量が小さいうちは敏感に感じ、大きくなるほど鈍感になる

::: tip UXデザインでの読み解き
「使い慣れた画面からの変更」はユーザーにとって参照点からの損失と感じられやすく、機能改善でも強い反発を招くことがあります。リニューアル時に丁寧な移行案内が必要なのは、損失回避性で説明できます。
:::

## ナッジ

ナッジ（nudge、そっと後押しする）とは、セイラーとサンスティーンが提唱した概念で、**選択の自由を残したまま、望ましい行動を後押しする設計**のことです。

- 選択肢を禁止しない
- 経済的インセンティブを大きく変えない
- 選択肢の見せ方や並べ方（**選択アーキテクチャ**）によって行動を方向づける

たとえば、納税案内のリンク先を「手続きの説明ページ」から「納付フォーム」に変えるだけで納付率が上がった事例があります。行動を強制せず、行動までの段差を小さくするのがナッジの考え方です。

### EASTフレームワーク

EASTは、英国の行動インサイトチーム（BIT）がまとめた、ナッジを実践するための4原則です。

| 原則 | 意味 | 工夫の例 |
|------|------|----------|
| Easy（簡単に） | 行動に必要な労力を減らす | デフォルトの活用、手順やメッセージの単純化 |
| Attractive（印象的に） | 関心を引き、魅力を感じさせる | 感情に訴える表現、自分事化できる内容、インセンティブ設計 |
| Social（社会的に） | 社会規範や人とのつながりに訴える | 「75%のお客様が再利用しています」という表示、周囲への公言を促す仕組み |
| Timely（タイムリーに） | 行動しやすいタイミングで働きかける | ライフイベントに合わせた案内、対処方針を事前に自分で計画してもらう |

EASTにFun（楽しさ）を加えた**FEAST**という派生形もあります。Attractiveの「楽しさ」の側面を強調したものです。

## ナッジ活用の注意点

ナッジは強力な手法だからこそ、使い方を誤ると害になります。

- ユーザーを欺いたり、不利な選択へ誘導したりする悪用は**スラッジ**と呼ばれ、ナッジとは区別される
- 解約ボタンを見つけにくくするような設計は、短期の数字を上げても信頼を失う
- ナッジが密かに操作的に使われていないか、公開性・選択の自由・ユーザーへの敬意の観点で点検する（FORGOODなどの倫理フレームワークがある）
- 同じナッジでも文脈によって効果が変わるため、効果を検証しながら使う

::: warning 倫理とのつながり
「企業の都合でユーザーを操作しない」という姿勢は、UXインテリジェンスの倫理観そのものです。詳しくは [lesson05](/lessons/lesson05/) を参照してください。
:::

## 試験のポイント

- シラバスの重要ワードは**ナッジ・プロスペクト理論・アンカリング効果・認知バイアス**の4つ。定義を正確に区別する
- ナッジの定義は「**選択の自由を残す**」「禁止や大きな経済的インセンティブの変更は含まない」が要点
- プロスペクト理論は「損失は同じ大きさの利得より強く感じられる」「価値は参照点からの変化で決まる」の2点が問われやすい
- EASTの4つの頭文字（Easy・Attractive・Social・Timely）と意味の対応を覚える
- ナッジの悪用（スラッジ）とナッジの違いを説明できるようにする
