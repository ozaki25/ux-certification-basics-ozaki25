# lesson15: アクセシビリティ — 誰もが利用できることの土台

## このレッスンで学ぶこと

- アクセシビリティの考え方と、対象が「すべてのユーザー」であることを理解する
- アクセシビリティとユーザビリティの関係（土台と上に積む使いやすさ）を説明できる
- ウェブアクセシビリティの規格（WCAG・JIS X 8341-3）と具体的な配慮の例を知る
- 障害者差別解消法など、日本のアクセシビリティをめぐる動向を知る

## アクセシビリティとは

アクセシビリティ（Accessibility）とは、**障害の有無・年齢・利用環境にかかわらず、誰もが情報やサービスに到達し、利用できること**を指す概念です。

JIS Z 8521 では「製品・システム・サービスなどが、特定の利用状況で目標を達成するために、ユーザーの多様なニーズ・特性・能力で使える度合い」と定義されています。要点は次の2つです。

- より**多様なユーザー**が使えること（年齢・身体機能・言語や文化の違いなど）
- より**多様な利用状況**で使えること（場所・時間帯・手がふさがっている場面など）

::: tip 障害のある人だけのためではない
アクセシビリティの対象は、障害者と認められた人に限定されません。たとえば動画の字幕は、聴覚障害のある人だけでなく、電車内で音を出せない人にも役立ちます。配慮の恩恵は障害のある人や高齢者が最も受けますが、効果はすべてのユーザーに及びます。
:::

## ユーザビリティとの関係

アクセシビリティとユーザビリティは、対象の広さと積み重ねの順序で整理できます。

| 観点 | アクセシビリティ | ユーザビリティ |
|------|------------------|----------------|
| 問い | そもそも到達・利用**できるか** | 利用できた上で**使いやすいか** |
| 対象 | できるだけ幅広いユーザー・利用状況 | 特定のユーザー・特定の利用状況 |
| 位置づけ | 前提・土台 | 土台の上に積み上げる品質 |

アクセシビリティが確保されていなければ、そのユーザーにとってユーザビリティを語る以前に「使えない」状態です。つまり**アクセシビリティは前提であり土台**で、利用できた上での使いやすさがユーザビリティ（[lesson14](/lessons/lesson14/)）です。

JIS X 8341-1 がアクセシビリティを「最も幅広い層の人々に対するユーザビリティ」と定義しているのも、この関係を表しています。

### ユニバーサルデザインとの関係

「できるだけ多くの人が利用できるように最初から設計する」というユニバーサルデザインの考え方は、アクセシビリティと方向性を共有しています。

- ユニバーサルデザイン: 特別な対応を後付けせず、初めから多様な人を想定して設計する思想
- アクセシビリティ: 到達・利用できる度合いという品質の観点

どちらも、多様なユーザーを理解して設計に反映するという点で、人間中心デザイン（[lesson06](/lessons/lesson06/)）の実践と深く関わります。

## ウェブアクセシビリティ

**ウェブアクセシビリティ**とは、アクセシビリティの考え方をウェブコンテンツに適用したものです。

スマートフォンの普及やEコマース・SNSの発展で、生活に必要な情報の多くがウェブを通じて提供されるようになりました。ウェブは、紙の読み書きや移動が困難なユーザーの課題を解決できる技術であるだけに、ウェブ自体が使えないことの影響は深刻です。

### 規格: WCAGとJIS X 8341-3

| 規格 | 内容 |
|------|------|
| WCAG | W3C が策定するウェブアクセシビリティの国際的な品質基準（Web Content Accessibility Guidelines） |
| JIS X 8341-3 | 日本の規格「高齢者・障害者等への配慮設計指針」のウェブコンテンツ編。WCAG 2.0 との一致規格 |

JIS X 8341-3 の品質基準は「**知覚・操作・理解・堅牢性**」の4つの観点で整理され、各基準には重要度に応じた「A・AA・AAA」の3段階のレベルがあります。

| レベル | ねらい |
|--------|--------|
| A | 「使えない」を防ぐための最低限の基準 |
| AA | 多くの場面で使いやすくするための基準 |
| AAA | すべてのユーザーが正確に使えるようにするための基準 |

### 具体的な配慮の例

- **代替テキスト**: 画像に説明文を付け、スクリーンリーダー（画面読み上げソフト）でも内容がわかるようにする
- **コントラスト**: 文字と背景の明暗差を確保し、弱視や屋外の強い日差しの下でも読めるようにする
- **キーボード操作**: マウスが使えない人でも、キーボードだけですべての機能を操作できるようにする
- 点滅の防止、フォームの誤送信対策、読み仮名の追加なども品質基準に含まれます

## 日本の動向

アクセシビリティは、法律や公的な指針によっても後押しされています。

- 2003年: 高齢者・障害者等への配慮設計指針（JIS X 8341）が誕生
- 2004年: ウェブを対象とした JIS X 8341-3 が誕生（2016年改正で WCAG 2.0 と一致）
- 2013年: **障害者差別解消法**が制定（2016年施行）
- 2024年4月: 改正法の施行により、**民間事業者も「合理的配慮」の提供が義務化**（努力義務から義務へ）

::: info 合理的配慮とは
障害のある人から社会的な障壁を取り除いてほしいと意思表示があったとき、負担が重すぎない範囲で対応することです。義務化により、アクセシビリティへの取り組みは「あると望ましい配慮」から「事業者が応える責務」へと位置づけが変わりつつあります。
:::

## 試験のポイント

- アクセシビリティの対象は障害のある人に限定されない。**多様なユーザー・多様な利用状況**で使える度合いという定義を押さえる
- ユーザビリティとの関係は頻出。**アクセシビリティは前提・土台**であり、利用できた上での使いやすさがユーザビリティという順序を覚える
- JIS X 8341-3 は **WCAG 2.0 との一致規格**で、知覚・操作・理解・堅牢性の観点と A・AA・AAA の3レベルを持つ
- 代替テキスト・コントラスト・キーボード操作は、ウェブアクセシビリティの代表的な配慮として具体例で問われやすい
- 障害者差別解消法の改正により、**2024年4月から民間事業者も合理的配慮の提供が義務**になった点を押さえる
