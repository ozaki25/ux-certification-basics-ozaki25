# lesson32: ユーザー視点での体験理解力 — AI時代に問い直されるユーザー理解

## このレッスンで学ぶこと

- AI時代においてもユーザー視点での体験理解がなぜ重要かを説明できる
- AIならではの価値と人間ならではの価値の違いを具体例とともに説明できる
- AIO対策で企業が注意すべき視点を理解する

## AI時代にUXの能力が重要になる理由

生成AIの登場によって、文章作成・情報整理・分析・アイデア出し・画像生成・プログラム作成など、多くの作業がAIによって支援・代替されるようになりました。今後はAIエージェントの普及によって、ユーザーに代わって判断の一部を行ったり、複数の作業を連続して実行したりする場面も増えていくと考えられます。

AIが多くの作業を担えるようになるからこそ、何を作るべきか、誰のどのような困りごとを解くべきか、どのような体験へ導くべきかを考えるUXの能力が、これまで以上に重要になります。

::: tip AIを礼賛も否定もしない
AI時代のUXで大切なのは、AIならではの価値と人間ならではの価値を見極め、それらを最適に融合しながらユーザーにとって最もよい体験を設計することです。
:::

## ユーザー視点での体験理解力とは

**ユーザー視点での体験理解力**とは、ユーザーがどのような状況に置かれ、どのような目的を持ち、どのような困りごとを抱えているかを、ユーザー側の視点から理解する力です。

年齢・性別・職業・趣味・性格といった属性を外から整理するだけでは、ユーザーが実際にどのような体験をしているかは分かりません。UXにおけるユーザー理解では、「ユーザーが見ている世界を、自分自身の視界として理解すること」が重要です。この考え方はAI以前から重要であり、AI時代でも変わりません。

作られたAIが使われない典型的な原因は、この体験理解自体が不十分で、「どのような困りごとに、どのような価値を届けるのか」が十分に考えられていないことにあります。

## AIならではの価値、人間ならではの価値

AI時代のUXでは、ユーザー理解に加えて「どの接点をAIに任せ、どの接点を人間が担うべきか」を考える力が重要です。

コールセンターを例に挙げます。人間の役割を完全にAIへ置き換える取り組みがこの数年試みられてきましたが、うまくいった例はほとんどありません。原因は、ユーザーから見た「AIに担ってほしい価値」と「人間に担ってほしい価値」が異なるのに、それをすべてAIに押し込もうとしていることにあります。考えるべき問いは「この業務はAIでできるか」ではなく、「この体験において、AIが担うべき価値と、人間が担うべき価値は何か」です。

| 側面 | 内容 |
|------|------|
| 心理的障壁の低さ | 英会話・子育て・健康・お金の悩みなど、人には相談しづらいこともAIになら気軽に話せる |
| 個別事情への対応 | レアケースと一般的な対応を組み合わせ、相手の個別事情に寄り添って回答できる |
| 汎用性 | 専門領域を越境する相談（お金の相談から仕事、子育てへと広がる等）にも一定品質で対応できる |
| 大量・安定供給 | 専門的なアドバイスを、人的リソースの限界を超えて大量かつ安定して提供できる |

一方、人間にしか提供できない価値もあります。たとえば、不安を感じる子どもに医療者が笑顔で声をかけ手を添えることは、身体性を伴う安心感の提供です。また、AIが方針を示しても、責任の所在が感じられないために人がそのまま信じきれないことがあります。責任の所在が明らかな人間が意思を持って背中を押すことで、初めて安心して意思決定できる場合があります。安心感・信頼感・人間性・身体性を伴う体験は、人間が関わるからこそ生まれる価値です。

::: warning AI化の判断軸
「この業務はAIに任せられるか」ではなく、「この体験でAIが担うべき価値と人間が担うべき価値は何か」を軸に設計します。
:::

## AIを使うユーザーの状況に寄り添う

AI時代には、ユーザー視点に立たず、AIという技術変化そのものへの最適化に偏りがちです。自社コンテンツをAIが理解しやすいように構造化したりメタデータを整えたりする対策（AIO対策）自体は重要ですが、それだけでは十分な体験は設計できません。

たとえば健康サプリメントを扱う企業がAIO対策をするなら、「サプリメントをどう検索されるか」ではなく、「正しく体調管理をしたい」「健康的に痩せたい」といったユーザーのニーズを捉え、その対応手段の1つとしてジョギングやヨガ、食生活アドバイスと並べて挙げられるようにする必要があります。

考えるべき問いは次のとおりです。

- ユーザーは生成AIにどのような質問をしているのか
- 通常の検索と異なり、AI上ではどのような対話が行われているのか
- どの質問がユーザーの意思決定にとって重要なのか
- その質問に対して、企業はどのような情報提供をすべきか

AI時代のUXでは、AIそのものを見るのではなく、AIを使っているユーザーを知り、その人の視点から自社の製品・サービスを眺めることが重要です。

## キーワード

| 用語 | 説明 |
|------|------|
| ユーザー視点での体験理解力 | ユーザーの状況・目的・困りごとを、ユーザー側の視点から理解する力 |
| AIならではの価値 | 心理的障壁の低さ・個別事情への対応・汎用性・大量安定供給など、AIが担うことで生まれる価値 |
| 人間ならではの価値 | 身体性を伴う安心感、責任の所在を伴う信頼など、人間が関わることで生まれる価値 |
| AIO対策 | AIが自社コンテンツを理解・引用しやすいように整える対策 |

## 試験のポイント

- AI時代でも「ユーザー視点での体験理解」自体は変わらず重要という前提を押さえる
- 「AIでできるか」ではなく「AIが担うべき価値・人間が担うべき価値は何か」という判断軸を理解する
- AIO対策は技術的対応だけでなく、AIを使うユーザーの状況理解とセットで考える点に注意する
